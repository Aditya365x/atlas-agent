# Atlas Labs Team Handbook

## On-call
The on-call rotation changes every Tuesday at 10:00 IST. The outgoing engineer writes a handover note in #oncall.

## Refunds
Refund requests above 5000 INR need manager approval. Smaller refunds can be issued by any support engineer.

## Deployments
We deploy to production Monday to Thursday. Friday deploys require a written rollback plan.
